PROGRAMACION

¿Que es la carrera de programacion?

Es una carrera que consiste en crear programas, páginas web y aplicaciones mediante computadoras y lenguajes de programación. Los estudiantes aprenderan a hacer codigos, diseñar páginas, organizar información y resolver problemas tecnologicos. Esta carrera es importante porque te permite desarrollar herramientas digitales que se utilizan en las escuelas, empresas y en los negocios.




Beneficios de la carrera

  • Desarrollas el pensamiento lógico y la creatividad.
  • Aprendes a resolver problemas usando la tecnología.
  • Adquieres conocimientos de programación y creación de páginas web.

¿Para que te sirve?

Te sirve para aprender a crear páginas web, aplicaciones para celulares y programas de computadora. También puedes desarrollar sistemas que ayuden a resolver problemas de empresas o negocios, organizar información y automatizar tareas. Al terminar, puedes buscar oportunidades laborales relacionadas con el desarrollo de software y continuar estudiando Ingeniería en Sistemas, Desarrollo de Software o carreras similares.

MODULOS DE PROGRAMACION


Módulo

I

Desarrolla software de sistemas informáticos

  • Diseña software de sistemas informáticos
  • Codifica software de sistemas informáticos
  • Implementa software de sistemas informáticos

Módulo

II

Desarrolla software con herramientas orientadas a la productividad

  • Emplea frameworks para el desarrollo de software
  • Aplica metodologías ágiles para el desarrollo de software

Módulo

III

Administra base de datos en un sistema de información

  • Implementa Base de Datos Relaciones en un sistema de información
  • Implementa Base de Datos no Relaciones en un sistema de información

Módulo

IV

Desarrolla aplicaciones web en un sistema de información

  • Construye aplicaciones web
  • Implementa aplicaciones web

Módulo

V

Desarrolla aplicaciones móviles multiplataforma

  • Diseña aplicaciones móviles multiplataforma
  • Implementa aplicaciones móviles multiplataforma
